# DummyAPI

В данном проекте разработана документация для тестироания через API объекта Post. На основе представленной на сайте документации составлена майнд-карта. На сонове майнд-карты разработан список тестов для коллекции запросов в POSRMAN. Для изучения объекта Post создано окружение - DummyAPI.
Для проверки всего цикла запросов, доступного для объекта Post (получение списка постов, создание поста, вывод поста по id, редактирование и удаление поста), создана коллекция запросов с автотестами.

## Описание проекта
Сайт https://dummyapi.io/. Dummy API - это готовый к использованию тренировочный API с большим объёмом данных (пользователи, посты, изображения, комментарии) для разработки, тестирования и обучения.
Для получения возможности выполнять запросы необходим app-id, который можно получить после регистрации на сайте. App-id передается в headers запроса. 
Для тестирования был взяты методы Get List и Create Post объекта **Post**.

### Post

#### GET /post (Get list)
Возвращает список постов, отсортированных по дате создания.
Для контроля элементов списка доступны следующие query params:
- page для вывода определенной страницы;
- limit для вывода определенного количества постов на странице.

**Response Body**

*List (модель data и массив со списком объектов модели Post Preview)*

*Mодель Data*
```javascript
{
data: Array(Model)
total: number(total items in DB)
page: number(current page)
limit: number(number of items on page)
}
```

*Модель Post Preview*
```javascript
{
id: string(autogenerated)
text: string(length: 6-50, preview only)
image: string(url)
likes: number(init value: 0)
tags: array(string)
publishDate: string(autogenerated)
owner: object(User Preview)
}
```

*Object Owner (модель User Preview)*
```javascript
{
id: string(autogenerated)
title: string("mr", "ms", "mrs", "miss", "dr", "")
firstName: string(length: 2-50)
lastName: string(length: 2-50)
picture: string(url)
}
```

#### POST /post/create (Create Post)
Создает новый пост. Возвращает данные о посте.

**Request body**

*Модель Post Create*
```javascript
{
text: string(length: 6-50, preview only)
image: string(url)
likes: number(init value: 0)
tags: array(string)
owner: string(User id)
}
```

**Response Body**

*Модель Post*
```javascript
{
id: string(autogenerated)
text: string(length: 6-1000)
image: string(url)
likes: number(init value: 0)
link: string(url, length: 6-200)
tags: array(string)
publishDate: string(autogenerated)
owner: object(User Preview)
}
```

*Object Owner (модель User Preview)*
```javascript
{
id: string(autogenerated)
title: string("mr", "ms", "mrs", "miss", "dr", "")
firstName: string(length: 2-50)
lastName: string(length: 2-50)
picture: string(url)
}
```
